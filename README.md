# AK 자연치유요법 12주 학습노트

고성윤 · AK 자연치유센터의 'AK 자연치유요법' 12주 과정을 회차별로 정리하는 개인 학습노트입니다.

- `index.html` — 12강 전체 목차와 진행 현황
- `lectures/NN.html` — 회차별 학습노트 (원고 + 강의 녹취 통합)
- `notes/NN.md` — 각 회차의 원본(마크다운). **수정은 여기서 합니다.**
- `build.py` — `notes/`를 읽어 `index.html`과 `lectures/`를 다시 만듭니다.

## 새 회차 추가 / 수정

1. `notes/02.md`처럼 파일을 만들고 맨 위에 다음 머리말을 넣습니다.
   ```
   ---
   num: 2
   title: 강의 제목
   date: 2026-10-01
   summary: 한 줄 요약
   ---
   ```
2. `pip install markdown` 후 `python3 build.py` 실행.
3. 바뀐 파일을 커밋합니다.

섹션 제목 뒤에 `{: .critical }`를 붙이면 '비판적 검토' 강조 상자로 표시됩니다. 다이어그램은 ```mermaid 코드블록으로 씁니다.
